# Clicker POC — 구현 계획

설계: [poc-design](2026-10-31-poc-design.md). 각 Task 끝에 `flutter analyze`와 `flutter test`가 통과해야 한다. core는 테스트를 먼저 쓴다.

## Task 0. 스캐폴드
- `flutter create --platforms=web,ios,android --org com.clicker --project-name clicker .`
- 기본 counter 앱과 테스트를 제거한다.
- `analysis_options.yaml`은 flutter_lints를 쓴다.
- 의존성: `image_picker`.

## Task 1. core/model
- `ClickerSpec`, `ClickerArt`(sealed), `FeelSettings`, `SoundSettings`, enum들, `copyWith`.
- `ClickerPack`: `toJson()`은 spec 메타와 에셋 키 맵을 만든다. `fromJson(json, assets)`.
- 테스트: JSON 왕복, pressed 없음 처리.

## Task 2. core/game
- `Clock`(typedef 또는 클래스)을 주입한다.
- `ComboEngine.tap(now) → ComboState{combo, max, tier, tierChanged}`. 창은 600ms.
- `TapRate`: 최근 1초 동안의 탭 수.
- `PlaySession(mode: free|timed10)`: `tap()`, `remaining`, `isOver`, `score`, `maxCombo`, 첫 탭부터 시간 측정.
- `RecordStore`: 클릭커별 최고 점수, 최고 콤보, 누적 탭. `submit()`은 신기록 여부를 반환한다.
- 테스트: 창 경계(600ms 포함, 601ms 리셋), 단계 경계값, 10초 종료 후 tap 무시, 신기록 판정.

## Task 3. core/feel
- `FeelPlanner.plan(settings, tier, tapsPerSecond, tapOffset /*-1..1*/) → FeelPlan`
  - 필드: `pressDepth`, `pressScale`, `tiltX`, `tiltY`, `springStiffness`, `springDamping`, `overshoot`, `shakeAmplitude`, `particleCount`, `fxSemitones`, `haptic`
- 규칙은 설계 6절을 따른다: 모션 끄기, 초당 8탭 초과 시 흔들림 절반, 파티클 상한 24, 기울기 최대 10°, 프리셋 차이.
- 테스트: 위 규칙 각각.

## Task 4. core/imaging
- `RgbaImage{w,h,Uint8List data}`.
- `connectedAlphaRegion(img, x, y, threshold=32)`: 4방향 BFS. 탭한 점이 투명이면 null.
- `featherAlpha(img, radius=1.5)`: 알파 채널만 박스 블러, 경계 부근만 처리.
- `cropToContent(img, paddingRatio=0.08)`.
- `fitTo(w,h, maxSide)`.
- 테스트: 두 덩어리 중 하나만 선택, 투명 탭 시 null, 크롭 박스, 페더 후 내부 알파는 255 유지.

## Task 5. platform 어댑터
- `segmenter.dart`: `abstract Segmenter { Future<Uint8List> removeBackground(Uint8List bytes, {void Function(double)? onProgress}); }`
  - 조건부 import: `segmenter_web.dart`(dart:js_interop, `window.clickerSeg.remove`) / `segmenter_stub.dart`(UnsupportedError).
- `sfx.dart`: `abstract SfxPlayer { void unlock(); void playSwitch(SwitchSound); void playEffect(EffectSound, {int semitones}); }`
  - web 구현은 `window.clickerSfx`, stub은 무음.
- `haptics.dart`: `HapticFeedback` 래퍼.
- `web/index.html`: imgly 모듈 스크립트(`@imgly/background-removal@1.7.0`, jsDelivr ESM, PNG 출력, progress 콜백)와 WebAudio 합성기.
- `imaging_io.dart` (Flutter 의존): bytes ↔ `RgbaImage` ↔ PNG. `dart:ui`를 쓴다.

## Task 6. widgets/clicker_stage.dart (핵심)
- 입력: `ClickerSpec`, `onTap(TapInfo)`, `tierListenable`, sfx/haptics 주입.
- `Listener`의 pointerDown에서:
  - 활성 포인터 추가
  - FeelPlan 계산
  - press 애니메이션(40ms)
  - 기울기 설정
  - 파티클 발사
  - 흔들림 시작
  - 사운드와 햅틱 재생
  - `onTap` 호출
- 마지막 포인터가 up/cancel되면 spring 반동을 시작하고 pressed 이미지를 원래대로 돌린다.
- 렌더: 그림자(타원, 깊이에 따라 축소) + `Transform`(perspective, rotateX/Y, translate, scale) + 이미지(`Image.memory`, gaplessPlayback) 또는 BuiltinArt 페인터 + 하이라이트 그라디언트.
- 파티클: 단일 `Ticker`와 `CustomPainter`. 객체 풀을 쓰고 수명은 450ms. shards는 이미지 일부를 `drawImageRect`로 그린다.
- 샘플 아트 `BuiltinArt`: `big_red_button`, `keycap`을 `CustomPainter`로 그린다.
- 위젯 테스트: pointer down마다 onTap 1회, 두 포인터면 2회. up 이후 다시 down해도 정상 동작.

## Task 7. data
- `ClickerRepository`(abstract): `list`, `add`, `get`, `changes`(Listenable).
- `InMemoryClickerRepository`: 샘플 2개를 시드로 넣는다.
- `AppScope`(InheritedWidget): repo, records, segmenter, sfx, haptics를 제공한다.

## Task 8. features
- **home**: 앱바 "Clicker". 탭은 "내 클릭커" / "마켓".
  - 내 클릭커: 카드 그리드(썸네일, 이름, 최고 기록). FAB "만들기".
  - 마켓: 준비 중 안내.
- **create**: 단계형 화면(`PageView` 없이 상태 enum으로 전환)
  1. 사진 고르기
  2. 분리: 진행률 표시 → 결과 미리보기(체커보드 배경). 원본을 탭해 보정, 되돌리기, 다음.
  3. 눌림 이미지(건너뛰기 가능)
  4. 튜닝: 상단 ClickerStage, 하단 옵션 칩
  5. 이름 → 저장 → 플레이로 이동
- **play**:
  - 상단 모드 토글(자유 / 10초)
  - HUD: 콤보, 최고, 남은 시간
  - 가운데 ClickerStage
  - 단계별 배경 그라디언트
  - 10초 종료 시 결과 바텀시트(신기록 배지, 다시하기)
  - 설정 아이콘: 모션, 사운드, 흔들림 강도 (전역 접근성 설정)
