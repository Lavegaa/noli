## 3. 확정된 결정

**제품**
- 타깃은 초·중학생이고, 모든 정책은 만 13세 미만 기준으로 설계한다.
- 연령 경계는 만 14세로 통일한다(14세 미만은 법정대리인 동의).
- 처음 5분에 "재밌다 → 친구랑 해봐야지 → 추천해야지"를 느끼게 하는 게 목표다.
- 웹 버전은 없다. 마켓도 앱 안에만 둔다. 유저 간 거래와 채팅은 넣지 않는다.
- 공개 출시는 v2 수익화 이후다. v1과 v1.5는 내부 체크포인트다.

**사물 분리**
- OS 내장 모델만 쓴다. iOS는 Vision `VNGenerateForegroundInstanceMaskRequest`, Android는 ML Kit Subject Segmentation이다.
- 모델을 앱에 넣거나 내려받지 않는다.

**스택**
- 앱: Flutter 3.47.
- 서버: NestJS 12, Prisma 7.10, PostgreSQL 17(docker compose).
- 인증·푸시: Firebase Auth(게스트로 시작해 계정 연결) + FCM.
- 그 외: S3 호환 저장소.

**수익**
- 가격은 990원 / 2,990원.
- 마켓은 올리기·받아가기만 하고, 접근권은 2,990원 패스로 판다.
- 패스 혜택: 광고 제거, 마켓 이용, 광고 없이 받는 뽑기권.
- 뽑기는 우리 오리지널 에셋만 다룬다: 스위치 등급, 이펙트, 오리지널 클릭커.
- 광고로도 뽑기권을 얻는다(예: 500번 누르기 → 광고 1회 → 뽑기권).

**제작과 보관**
- 제작 제한: 5번 만들 때마다 광고 1회.
- 보관함 칸은 제작 제한과 별개다. 만든 것, 받은 것, 오리지널을 한 칸으로 통합해 센다.
- 칸이 꽉 차면 "지우고 만들기" 또는 칸 구매. 최대치에서는 지우기만 가능하다.
- 스위치 합성 대신 장착 칸을 늘린다.

**안전**
- 서버 규칙(2026-11-01): 생년월일은 한 번만 입력, 사진 업로드는 공유 권한이 있을 때만, 클릭커를 지우면 모든 곳에서 사라짐(받은 사람 보관함·플레이·공유·랭킹 모두, 칸 반환), 다시 공유한 코드로는 코드를 건넨 사람과만 친구가 됨, 차단하면 친구 관계도 끊김, 이미지 검사로 숨긴 클릭커는 신고 복구로 풀리지 않음.
- 클릭커를 만드는 순간 얼굴 감지와 동의 확인을 한다.
- 신고 3건이 쌓이면 제작자의 업로드를 제한한다.

**클릭커 형태**
- **위 캡**: 잘라낸 사물에 광택 레진을 입힌 것.
- **아래 몸통**: 같은 윤곽을 더 부풀린 무광 몸통. 색은 장착한 스위치 색(빨강축/갈축/파랑축 등).
- **이음새**: 캡과 몸통 사이에 둔다. 누르면 캡 옆면이 18→5px로 줄며 이음새가 닫힌다.
- 바닥 그림자와 모서리를 어둡게 하는 처리는 넣지 않는다(기획자가 품질이 떨어진다고 판단).
- 키링 고리는 넣지 않는다(게임 속 물건이라 필요 없음).
- 구현 방식:
  - 클릭커를 만들 때 이 모양을 **이미지로 한 번 구워** 저장한다.
  - 플레이 중에는 이미지 2~3장을 바꿔 끼우기만 한다.
  - 몸통은 회색으로 구워 두고 실행 중에 색만 입히는 방식을 검토한다.
- 참고 스크립트: `docs/research/clicker-form/two-piece/twopiece_gen.py` (Python, numpy/scipy).

**화면**
- 게임 쪽 디자인으로 간다(G2 소프트 글로시 방향). 다만 G2의 색감은 어중간했다.
- 홈 가운데 클릭커를 누르면 다른 UI가 가장자리로 빠지며 바로 플레이가 시작된다.
- 콤보 게이지는 원형 대신 **상단 바형**으로 한다. 게이지가 차오르는 연출은 "아주 좋다"는 반응이었다.
- 판이 끝나면 **결과·보상 화면이 필수**다. 없으면 "체험판" 같다는 반응이었다.
- 미니게임(10초 대결, 7.77초, 리듬)은 홈에서 빼고 별도 탭으로 둔다.
- 서랍장은 보유 클릭커 목록이다(피젯보드 정리함 느낌).

**마스코트**
- 강아지 + 고양이 2종이다.
- 고양이 이름은 **꾹꾹이**로 정했다. 발바닥 모양 클릭커 같은 파생 아이템도 만든다.
- 강아지 이름은 미정이다. 제안한 후보는 딸깍이 / 콩떡이 / 딸깍멍.
- 메인 컬러는 마스코트에서 뽑는다.
- 마스코트의 표정은 안내·결과·이모티콘에만 쓴다.

**운영 규칙**
- 디자인 시안과 리서치는 **기획 문서에 넣지 않고 아카이빙만** 한다(기획자 지시).

## 4. 기각된 방향 (다시 제안하지 말 것)

| 방향 | 기각 이유 |
|---|---|
| 아케이드·키보드 홈 | 별로 |
| 파스텔 + 두꺼운 테두리 + 오프셋 그림자 스타일 | 지겹다 |
| 동그라미 액자 클릭커 / 스티커 같은 클릭커 | 사물 모양 그대로여야 함 |
| 바닥·무대 위에 세운 사물 | "피규어"지 클릭커가 아님 |
| 캐릭터를 스위치 몸통 위에 얹기 | 안 예쁨 |
| 표정으로 콤보 단계 표시 | 사진 클릭커엔 얼굴이 없음 → 콤보 연출은 사물을 가리지 않는 것만(빛, 파티클, 화면) |
| 받침 없는 실루엣 버튼만 | 게임 느낌은 좋지만 클릭커처럼 안 보임 |
| 같은 모양 복사본을 어긋나게 겹친 두께 | 겹친 종이처럼 보임 |
| 큰 사각 받침 | 앱 아이콘 같음 → 캡+몸통으로 대체 |
| drop-shadow 수십 겹 실시간 필터 | 심한 렉 → 이미지로 미리 굽기 |

## 6. 작업하며 알게 된 함정

- **Prisma AI 안전장치:** `prisma migrate reset`은 AI 에이전트가 실행하면 거부된다. 테스트 DB는 tmpfs 컨테이너 + `migrate deploy` + 테이블 TRUNCATE로 운영한다. 안전장치를 우회하지 않는다.
- **스위치 카탈로그:** 서버가 켜질 때 자동으로 넣는다(멱등). 서버를 여러 대로 늘리기 전에 동시 시작 경합을 막아야 한다.

- **공개 저장소 주의:**
  - `docs/research/`에는 남의 이미지가 있다: 앱스토어 스크린샷, MakerWorld 사진, 뉴스 사진.
  - 같은 폴더에 기획자의 개인 사진(강아지)도 있다.
  - 그래서 이 폴더는 .gitignore로 저장소에서 뺐다. 새 세션에서는 로컬 `/Users/cudy/projects/noli/docs/research`에만 있다.

- **macOS 첫 실행 차단**: Homebrew로 설치한 Flutter의 `dartaotruntime`이 macOS Gatekeeper에 막혔다. 기획자가 직접 `xattr -dr com.apple.quarantine /opt/homebrew/share/flutter`를 실행해 풀었다.
- **누끼 가장자리**:
  - 뒤 배경(울타리 등)이 털 가장자리에 회색 테두리로 남는다.
  - 가장자리 띠의 어둡고 색 없는 픽셀만 지우면 해결된다.
  - 단, 무조건 적용하면 콜라캔처럼 원래 어두운 테두리가 있는 물건이 갉아먹힌다. 조건부로 써야 한다.
- **사진 회전**: 아이폰 HEIC는 회전 정보(EXIF)를 반영해야 한다. 반영하지 않으면 옆으로 누운 채 잘린다.
- **문서 조회 도구**: Context7 MCP는 현재 인증이 필요해 쓸 수 없다. 서버 계획은 "Context7로 문서 확인"을 요구하므로, 공식 문서를 웹에서 직접 확인한다.
- **포트**: 이 Mac에는 다른 프로젝트의 Docker 컨테이너(`lunchfairy-fairy-codex`)가 떠 있다. 서버 계획의 DB 포트 5432/5433은 2026-11-01 기준 비어 있다.
