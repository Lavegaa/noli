# Clicker Platform — Product Brief

## 한 줄 정의

누구나 사진 속 사물을 손맛 있는 디지털 클릭커로 만들고, 공유하고, 수집하고, 플레이 기록으로 경쟁하는 모바일 UGC 플랫폼.

## 제품의 약속

- 어떤 이미지든 제작의 재료가 된다.
- 만든 클릭커는 보기만 좋은 스티커가 아니라 누르는 재미가 있어야 한다.
- 좋은 제작자는 다운로드·플레이·업적을 통해 발견되고 보상받는다.

## 핵심 루프

```text
사진/이미지 선택 → AI 분리와 꾸미기 → 클릭커 플레이 → 콤보·기록 획득
       ↑                                               ↓
       └── 슬롯/칭호/발견 동기 ← 마켓 공유·다운로드·반응 ──┘
```

## 제작 경험

1. 사진에서 주된 사물을 자동 분리한다.
2. 결과가 틀리면 사용자가 대상 사물을 탭해 재분리를 요청한다.
3. 기본 이미지와 눌렀을 때 이미지를 각각 설정할 수 있다. 예: 주먹 → 따봉.
4. 별도 이미지가 없으면 프레스 모션으로 눌림 상태를 자동 생성한다.
5. 스위치 소리와 효과음을 각각 선택·켜기·끄기 한다.
6. 모션 프리셋과 파티클을 선택한 뒤 즉시 미리본다.

## 클릭 손맛

첫 버전은 실제 3D가 아닌 2.5D를 사용한다.

- **프레스:** 터치 중 아래로 이동, 약간 축소, 그림자 축소, 하이라이트 변화.
- **반동:** 손을 뗄 때 원위치보다 아주 조금 튀었다가 안정화.
- **미세 흔들림:** 누른 충격을 전달하는 짧고 작은 화면/오브젝트 흔들림. 연속 클릭 시 강도는 제한해 멀미와 피로를 막는다.
- **파티클:** 타격 지점에서 작은 별·스파크·이미지 테마 파편 등이 짧게 나온다.
- **사운드:** 기계적 스위치 소리와 이미지/테마에 맞는 효과음을 독립적인 두 레이어로 재생한다.
- **접근성:** 모션 및 사운드를 끌 수 있고, 흔들림 강도는 낮춤/기본/강함으로 설정한다.

## 콤보와 기록

콤보는 정해진 시간 안에 연속 터치하면 올라가며, 간격이 길어지면 끝난다. 버튼의 기본 쓰임을 해치지 않도록, 게임 모드 또는 선택 가능한 기록 모드에서 전면에 노출한다.

- 현재 콤보, 최고 콤보, 총 클릭 수를 보여준다.
- 콤보 구간마다 모션·파티클·사운드가 한 단계씩 강해진다.
- 최고 콤보는 클릭커별 기록과 사용자 전체 기록으로 저장한다.
- 향후 대결/기간 이벤트를 추가할 수 있으나, 초기에는 비동기 기록 경쟁으로 시작한다.

## 마켓플레이스와 소셜

- 누구나 클릭커를 무료로 게시한다.
- 탐색은 인기, 신규, 테마, 제작자, 친구/팔로우 기반으로 제공한다.
- 각 작품은 제작자, 다운로드 수, 총 플레이 수, 최고 콤보, 태그, 미리보기를 가진다.
- 사용자는 내려받은 클릭커를 자기 라이브러리에 추가하고 플레이한다.
- 신고·비공개·저작권/초상권 대응 정책은 공개 마켓 출시 전 필수다.

## 랭킹과 칭호

### 플레이어

- 총 클릭 수, 클릭커별 최고 콤보, 주간 최고 콤보를 기준으로 랭킹을 제공한다.
- 예시 칭호: `첫 딸깍`, `연타의 달인`, `콤보 수집가`, `번개손`.

### 제작자

- 게시 수, 누적 다운로드, 누적 플레이, 여러 작품의 일정 다운로드 달성을 기준으로 칭호를 준다.
- 예시 칭호: `첫 작품`, `인기 제작자`, `천 번 눌린 작품`, `마켓 메이커`.
- 칭호와 레벨은 프로필, 마켓 카드, 리더보드에 노출해 발견성을 높인다.

## 보상과 수익화

- 게시 자체는 무료다.
- 다운로드 권한은 한 번의 결제로 전체 작품을 해금한다. 반복 구독보다 진입장벽을 낮춘다.
- 기본 클릭커 슬롯은 제한하고, 추가 슬롯은 구매할 수 있다.
- 출시 초반에는 업적·이벤트·제작자 마일스톤으로 슬롯 일부를 무료 지급해, 과금이 제작을 막는 인상은 피한다.
- 수익을 좌우하는 다운로드 해금 가격, 기본 슬롯 수, 보상 슬롯 수는 베타 테스트로 결정한다.

## 초기 범위 순서

1. **POC:** 이미지 자동/탭 기반 분리, 2.5D 클릭, 사운드, 미리보기.
2. **Creator alpha:** 저장 가능한 클릭커, 기본 라이브러리, 별도 눌림 이미지와 모션/사운드 설정.
3. **Marketplace beta:** 게시·탐색·다운로드·신고, 기본 제작자 통계.
4. **Engagement:** 콤보·기록·칭호·랭킹·업적 보상.
5. **Monetization:** 전체 다운로드 해금과 추가 슬롯. 보상 설계 검증 후 적용.

## 아직 결정할 것

- 마켓의 작품 다운로드가 기기 로컬 파일인지 앱 내 라이브러리 항목인지.
- 이미지 분리를 기기에서 할지 서버에서 할지, 그리고 사용자 이미지 보관 정책.
- 콤보의 시간 창과 랭킹 부정행위 방지 방식.
- UGC 콘텐츠 검수와 신고 처리 기준.
- 기본 슬롯 수, 전체 다운로드 해금 가격, 보상 슬롯의 정확한 기준.
