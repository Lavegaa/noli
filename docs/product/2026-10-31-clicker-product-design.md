# Clicker — 상세 기획 (v1 ~ v2)

> 상위: [product brief](2026-10-31-clicker-platform-product-brief.md) · 선행 작업: [POC 설계](../design/2026-10-31-poc-design.md)
> 이 문서는 brief의 방향을 유지하되, 타깃(초·중학생)과 친구 중심 확산에 맞춰 범위·수익 구조·안전 장치를 구체화한다. brief와 충돌하면 이 문서가 우선한다.
> 표기: **[결정]** = 기획자가 정함 · **[Claude 판단]** = 대화 중 Claude가 정했고 기획자가 검토할 항목 · **[빌더]** = 구현자가 정해도 됨 · **[베타]** = 테스트 데이터로 정함

---

## 1. 왜 만드는가

**한 줄**: 아이들이 자기가 고른 물건으로 웃기고 손맛 좋은 클릭커를 만들어 친구에게 자랑하고, 친구가 눌러보고 "나도 만들래" 하게 되는 앱.

**목표 감정** [결정]: 처음 5분을 쓴 아이가 "재밌다 → 친구랑 해봐야지 → 추천해야지"를 느끼고 나간다.

**핵심 장면** [결정]: 쉬는 시간, 내가 원하는 사물(장난감·물건·밈)로 더 재미있는 클릭커를 만들어 친구에게 보여주고, 친구가 눌러보고 반응한다.

**타깃** [결정]: 초·중·고 학생, 그중 **초·중학생이 주 타깃**. 따라서 모든 정책은 **초등학생(만 13세 미만)을 기준**으로 설계한다.

## 2. 목표 · 비목표 · 안티목표

**목표**
- 사진 한 장으로 1분 안에 "자랑할 만한" 클릭커를 만든다.
- 친구 간 공유가 자연스러운 설치 확산으로 이어진다.
- 매일 돌아올 이유(퀘스트·뽑기·내 작품 반응·친구 랭킹)가 있다.
- 출시 시점에는 수익 구조(보관함 칸·광고·패스·뽑기)를 갖춘다.

**비목표**
- 유저 간 거래·판매(마켓은 "올리고 받아가기"만, 돈이 오가지 않음) [결정]
- 채팅·DM [Claude 판단: 아동 안전]
- 웹 버전 [결정: 앱만, 마켓도 앱 내]
- 실제 3D 렌더링 (2.5D 유지)

**안티목표** (기술적으로 돌아가도 실패로 본다)
- 친구·선생님 얼굴 클릭커가 놀림·괴롭힘 도구가 되는 것
- "아이들 상대로 뽑기 과금하는 앱"이라는 부모 평판
- 결제 때문에 만들기·놀기가 막힌다는 인상 (brief의 원칙 유지)
- 끝없는 스크롤로 과몰입을 유도한다는 비판

## 3. 제약 (법·스토어 정책)

> 법률 자문이 아닌 기획 단계 정리. 출시 전 전문가 검토 필수 [결정].

| 영역 | 제약 | 기획 반영 |
|---|---|---|
| 개인정보 | 만 14세 미만 가입 시 법정대리인 동의 (개인정보보호법) | 가입 없이 시작, 계정이 필요한 순간에만 보호자 동의 (§6.10) |
| 결제 | 미성년자 무동의 결제는 취소 가능 (민법) | 스토어 보호자 승인(Ask to Buy / Google 가족 결제) 전제, 환불 정책 명시 |
| 확률형 아이템 | 유료 확률형 확률 공개 의무 (게임산업법, 2024.3~), 애플·구글도 공개 요구 | 뽑기권 **직접 판매 없음**, 확률 공개, 중복 보상, 천장 (§6.6) |

## 4. 용어

| 용어 | 뜻 |
|---|---|
| 클릭커 | 이미지(기본 + 선택적 눌림 이미지) + 장착한 스위치들. 내가 만든 것 / 받은 것 / 오리지널(우리가 만든 것) 3종 |
| 사운드 스위치 | 누를 때 나는 소리. 키보드 스위치처럼 다양, 등급별 |
| 이펙트 스위치 | 누를 때 반응: 모션(프레스·반동·회전 등), 파티클(튀는 효과·주변 상시 파티클) |
| 장착 칸 | 스위치를 끼우는 칸. 기본 사운드 1 + 이펙트 1. 이펙트 칸을 늘리면 효과가 겹침. 칸 자체가 획득 에셋 |
| 보관함 칸 | 클릭커를 보관하는 칸. 만든 것·받은 것·오리지널 **통합** |
| 조각 | 퀘스트·중복 보상으로 모으는 재화. 5개 = 뽑기 1회 [Claude 판단: 개수는 베타] |
| 패스 | 2,990원 1회 구매(또는 기간제, §6.8). 광고 제거 + 마켓 이용 + 광고 없이 보상 |

## 5. 정보 구조

하단 탭 5개 [Claude 판단, 목업 승인됨]: **홈 · 탐색 · 만들기 · 랭킹 · 나**

- 홈: 오늘의 퀘스트, 뽑기 진행도, 내 작품 소식
- 탐색: 쇼츠형 피드 (탭: 친구 · 추천 · 신규 · 테마) — v1.5
- 만들기: 제작 플로우 진입 (보관함 칸 확인 → 사진 → 분리 → 눌림 이미지 → 장착 → 저장)
- 랭킹: 친구 / 이번 주 전체(v1.5) × 최고 콤보 / 총 클릭 / 내 작품 인기
- 나: 보관함(내 클릭커), 스위치 컬렉션, 친구, 설정(모션·사운드·흔들림), 계정·보호자, 구매

목업: `.superpowers/brainstorm/*/content/return-loop.html` (쇼츠·랭킹·홈 3화면, 기획자 승인)

## 6. 기능 상세

### 6.1 만들기
1. **보관함 칸 확인 (시작 시점)** [결정]: 꽉 찼으면 "지우고 만들기" / "칸 늘리기(구매·무료 보상)". 칸이 최대치면 "지우고 만들기"만. 지울 때 기록도 사라짐을 확인 [Claude 판단].
2. **첫 제작 동의** [결정]: 최초 1회, 아이 눈높이 그림+짧은 문장 3~4개 ("다른 사람 얼굴로 만들지 않아요", "남의 그림·캐릭터를 내 것처럼 올리지 않아요", "문제가 있으면 신고로 내려갈 수 있어요").
3. **사진 → 분리**: OS 내장 분리 (iOS 17+ Vision 인스턴스 마스크, Android ML Kit Subject Segmentation). 여러 사물이면 탭해서 하나 선택. 테두리 정리(침식·색 번짐 제거·페더·크롭)는 POC 로직 재사용.
4. **기기 내 검사** [Claude 판단]: 얼굴 감지(Vision / ML Kit) → "얼굴 포함" 표시. 선정성 감지는 플랫폼 가능 범위(iOS SensitiveContentAnalysis 사용 조건 확인 필요, Android는 소형 모델 검토) → 감지 시 저장 차단. **사진은 이 단계에서 서버로 보내지 않음.**
5. **눌림 이미지** (선택): 같은 파이프라인.
6. **장착**: 보유 스위치 중 사운드·이펙트 선택, 실시간 미리보기 (POC의 ClickerStage).
7. **이름 → 저장**.

**제작 횟수 제한** [결정]: 여유 있게. 무료로 계속 만들 수 있고 **5회 제작마다 보상형 광고 1회** (v2). 패스 보유자는 광고 없음. v1에는 광고 없음 → 제한 없음 [Claude 판단].

### 6.2 플레이
- POC 그대로: 포인터 다운 즉시 반응, 2.5D 프레스·기울기·반동·흔들림(상한)·파티클, 사운드 2레이어, 햅틱(앱).
- 모드: 자유(무한 콤보) / 10초 챌린지. 콤보 창 600ms, 단계 calm <10 / charged 10–29 / wild 30–59 / frenzy 60+.
- 장착 이펙트가 여러 개면 엔진이 효과를 합성하되 흔들림·파티클 상한 유지.
- 기록: 클릭커별 최고 점수·최고 콤보·누적 클릭 → 서버 동기화(랭킹·소식용).
- 접근성: 모션 끄기, 사운드 끄기, 흔들림 약/보통/강.

### 6.3 장착과 스위치
- 클릭커마다 장착 칸: 기본 사운드 1 + 이펙트 1 [Claude 판단].
- **장착 칸은 계정 단위** [Claude 판단]: "내 이펙트 칸 N개"가 모든 클릭커에 적용. 칸은 뽑기·보상으로 획득 [결정]. 최대치 존재 (예: 이펙트 4칸) [Claude 판단, 수치는 베타].
- 받은 클릭커·오리지널 클릭커에도 내 스위치를 바꿔 낄 수 있음 [Claude 판단]. 공유 시에는 제작자가 장착한 구성이 기본값으로 전달되고, 받는 사람이 그 스위치를 보유하지 않으면 **그 클릭커 안에서만** 체험 가능 [Claude 판단 — 자랑 효과 + 뽑기 동기].
- 등급 4단계: 일반 / 레어 / 에픽 / 레전드 [Claude 판단]. 높은 등급일수록 소리·이펙트 모두 독특 (예: 누를 때 90° 회전, 특이한 파티클, 주변 상시 파티클) [결정].
- 기존 "합성" 아이디어는 **장착 칸 확장으로 대체** [결정].

### 6.4 친구
- **공유** [결정]: 내 클릭커 → "친구에게 주기" → QR(같은 자리) / 6자리 코드·링크(메시지). 앱 없는 친구가 링크를 누르면 스토어로 → 설치 후 자동 수령 (디퍼드 딥링크).
- **친구 등록** [Claude 판단]: 클릭커를 QR·코드로 주고받으면 양쪽 동의 하에 친구 등록. 별도 검색·추천 친구 없음(아동 안전).
- 받은 클릭커는 받는 사람의 보관함 칸을 차지, 제작자 표시.
- **내 작품 소식**: 친구가 내 클릭커로 세운 기록·받기 수 알림 (푸시 + 홈 카드).
- 공유 시 서버 검사 (선정성·폭력). 얼굴 포함 표시가 있으면 경고 후 허용 [Claude 판단 — 기획자가 차단으로 바꿀 수 있음].
- **공유 데이터 모델** [Claude 판단]: 공유·마켓의 클릭커는 서버 **원본을 참조**하고, 받은 기기는 오프라인 플레이용 사본을 캐시한다.
  - 신고·저작권으로 원본이 숨겨지면 받은 사람 보관함에서도 숨김 (즉시 중단 요건).
  - 제작자가 수정하면 받은 사람에게도 반영.
  - **제작자가 삭제하면 모든 곳에서 사라진다** [결정 2026-11-01]: 받은 사람 보관함에서도 빠지고(칸 반환), 플레이·공유·코드 받기가 모두 막힌다. 신고로 숨긴 것과 같은 취급.
  - 받은 클릭커는 친구에게 다시 줄 수 있음(원 제작자 표시 유지). 마켓 올리기는 원 제작자만.

### 6.5 홈 · 일일 퀘스트
- 매일 4개 내외 [Claude 판단]. 예: 클릭 1,000번 / 친구 클릭커 2개 눌러보기 / 콤보 30 / 탐색에서 5개 눌러보기 / 새 클릭커 만들기.
- 보상: 조각. 조각 5개 = 뽑기 1회.
- 퀘스트 목록·보상량은 [베타].

### 6.6 뽑기
- 대상: 사운드 스위치, 이펙트 스위치, 장착 칸, 오리지널 클릭커 [결정].
- 획득 경로: 퀘스트 조각, (v2) 클릭 500회마다 광고 1회 시청 → 뽑기권, (v2) 패스 보유자는 광고 없이 500회마다 [결정].
- **안전 원칙** [Claude 판단, 기획자 동의]: 뽑기권·조각 **직접 판매 없음**, 확률 공개(앱 내 + 스토어 요건), 중복 → 조각 환급, 천장(N회 내 에픽 이상 확정, N은 베타).
- v1: 조각으로만 뽑기 (유료 경로 없음). **v1 뽑기 대상은 사운드·이펙트 스위치만**, 이펙트 장착은 1칸 고정 → 이펙트 겹치기·장착 칸 뽑기·오리지널 클릭커는 v2 [Claude 판단: §7과 일치시킴]. v1 등급별 특수 이펙트(회전·상시 파티클 등)는 소수만.
- 클릭 수 기반 보상은 오토클리커 악용 가능 → 서버에서 비정상 속도 제한 [빌더].

### 6.7 탐색 · 마켓 (v1.5)
- 쇼츠형 세로 피드, 한 장에 클릭커 하나, 그 자리에서 바로 눌러봄 [결정, 목업 승인].
- 오른쪽: 받기 수, 최고 콤보, 공유, 신고. 하단: 친구 기록, "내 클릭커로 받기(보관함 n/m)".
- 탭: 친구 · 추천 · 신규 · 테마.
- 마켓은 거래 없음: 올리고, 다른 사람이 받아감 [결정]. **마켓 이용(받기) 권한은 패스에 포함** [결정]. 올리기는 무료 [Claude 판단: brief의 "게시 무료" 유지].
- 일정 개수 연속 시청 시 "잠깐 쉬어 갈까요?" [Claude 판단].
- 올리기 시: 서버 검사 + 얼굴 포함이면 **공개 불가(또는 검수 대기)** [Claude 판단].
- 운영자 큐레이션(추천 탭 상단 등)은 검수된 것만 [Claude 판단: OSP 면책].

### 6.8 수익화 (v2, 출시 전 완비)
| 상품 | 내용 | 비고 |
|---|---|---|
| 보관함 칸 | 추가 칸 구매 (예: 990원) | v1부터. 업적·이벤트로 무료 지급도 |
| 패스 2,990원 | 광고 제거 + 마켓 이용권 + 광고 없이 500회마다 뽑기권 | 1회 구매 vs 기간제 미결 (§9) |
| 광고 | 5회 제작마다 1회, 클릭 500회마다 시청 시 뽑기권 | 보상형만, 13세 미만 비맞춤 |
- 가격대 990 / 2,990원 [결정, 정확한 수치는 베타].

### 6.9 안전 · 저작권 운영
**콘텐츠 검사 단계** [Claude 판단, 기획자 동의]
| 시점 | 위치 | 검사 | 처리 |
|---|---|---|---|
| 만들 때 | 기기 | 얼굴, (가능 시) 선정성 | 얼굴 → 표시만 / 선정성 → 저장 차단 |
| 친구에게 줄 때 | 서버 | 선정성·폭력 | 차단 / 얼굴 포함 경고 |
| 마켓 올릴 때 | 서버 + 사람 | 위 + 얼굴 | 얼굴 → 공개 불가·검수 대기 |
- 신고 → 즉시 숨김 → 검수. 차단(특정 유저의 콘텐츠·공유 거부).
- 저작권 절차(v1.5 전 완비): 신고 수령인 지정·공지 / 즉시 중단 + 권리자·게시자 통보 / 게시자 소명 시 재게시 / 반복 침해자(예: 3회) 업로드 제한 / 약관(권리 보증·게시 라이선스·삭제 권한) / 침해물 홍보·수익 활용 금지.
- 우리 오리지널 에셋(스위치 소리·이펙트·클릭커)은 직접 책임 → 외주·AI 생성물 권리 정리 [빌더+운영].

### 6.10 계정 · 보호자
- 첫 실행: 연령 확인(중립적 질문) → 13세 미만 여부 저장 (광고·기능 정책 분기).
- 가입 없이 시작: 기기 계정으로 만들기·플레이·퀘스트 가능.
- **기기 계정의 서버 저장** [Claude 판단, 법률 검토 대상]: 서버에 무작위 계정 ID로 플레이 기록·퀘스트·조각·뽑기·보유 스위치를 저장한다 (보상 검증·오토클리커 차단·랭킹 기준이 서버여야 하므로). 이름·연락처·광고 ID 등 개인 식별 정보는 보호자 동의 전에 수집하지 않으며, 사진은 공유 전까지 서버로 보내지 않는다. 정식 계정 전환 시 같은 ID를 이어 쓴다.
- 정식 계정이 필요한 순간: 친구 공유, 마켓 올리기, 결제, 기기 이전. Apple/Google 로그인.
- 만 14세 미만: 이때 **보호자 동의** 절차 (보호자 휴대폰 본인인증 등 방식은 §9). 약관 동의 함께.
- **나이 기준** [Claude 판단]: 한국 출시 기준 **만 14세 하나로 통일** (보호자 동의 + 비맞춤 광고 모두 14세 미만에 적용). 해외 출시 시 국가별 분리.
- **가입 방식** [Claude 판단]: 게스트 계정(서버 발급 무작위 ID)으로 시작 → 필요한 순간 Apple/Google(/Kakao) OAuth를 **같은 계정에 연동** → 연동 시 생년월일 입력(중립적 연령 확인) → 14세 미만이면 보호자 동의.
- **받는 쪽** [Claude 판단, 기획자 이견 없음]: 링크·QR로 받은 클릭커는 게스트 상태로 바로 받고 플레이. 친구 등록·내가 공유하기·마켓 올리기·결제부터 정식 계정(+14세 미만은 보호자 동의).
- **단계적 구현** [결정]: 체크포인트 동안은 14세 이상 기준으로 만들고, 보호자 동의 플로우(본인인증 연동·동의 화면)는 **출시 전(v2)** 에 추가한다. 단, 나중에 바꾸기 비싼 다음 구조는 **v1부터** 넣는다:
  - 계정 모델에 생년월일(또는 연령대)·동의 상태·연동 수단 필드
  - 서버에 기능 권한 게이트 한 곳(공유·친구 등록·마켓 올리기·결제·광고 모드) — 나중엔 동의 상태만 바꾸면 열림
  - 동의 전 최소 수집 원칙 (개인 식별 정보·광고 ID·사진 미수집)
  - 광고 SDK 아동 대상 설정 스위치
- 체크포인트 테스터가 14세 미만이면 앱 밖에서(서면·온라인 양식) 보호자 동의를 받는다.

### 6.11 운영 — 1인 개발 + AI 운영
**전제** [결정]: 기획자 1인 개인 프로젝트. 운영은 AI를 최대한 활용한다.

**원칙** [Claude 판단]
- **먼저 숨기고, AI가 1차 판단, 사람은 애매한 것만**: 신고가 들어오면 자동으로 즉시 숨긴다. AI가 이미지 검사 결과·신고 사유·제작자 이력을 보고 복구/삭제/보류로 분류한다. 기획자는 "보류"와 저작권 소명만 하루 1회 처리한다.
- **AI 판단은 기록이 남는다**: 판단 근거를 저장해 오판을 되짚고 기준을 고칠 수 있게 한다. 저작권 통보·재게시처럼 법적 절차가 걸린 건 AI가 초안을 쓰고 기획자가 확정한다.
- **관리자 웹은 최소한**: 검수 대기 목록, 콘텐츠 상세(원본·검사 결과·AI 판단), 처리 버튼, 유저 제재, 확률표·퀘스트 수치 수정. React로 단일 페이지.
- **직접 만들지 말고 관리형 서비스 우선**: 1인 운영 부담을 줄이는 쪽을 고른다 (§8).
- 운영 지표(신고 수, 자동 처리율, 보류 대기 시간)를 관리자 웹 첫 화면에 둔다.

## 9.5 후속 아이디어 (범위 밖, 기록용)

**미니게임** (같은 클릭커·스위치 엔진 위의 모드)
- 10초 대결: 친구와 누가 더 많이 누르나. 첫 단계는 같은 폰 번갈아 하기 또는 친구 기록(고스트)과 비동기 대결, 실시간 대결은 서버 필요.

**파생 장난감** (말랑이, 왁뿌볼 등)
- 사진 → 분리 파이프라인·보관함·마켓·뽑기는 공유하고, 상호작용(누르기 vs 주무르기·당기기·터뜨리기)만 다른 "장난감 종류"로 보는 안이 유력 [Claude 판단]. 시리즈 앱 분리 vs 한 플랫폼 확장은 클릭커 검증 후 결정.
